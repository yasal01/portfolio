# Yasal — UI/UX & Website Development Portfolio

A dedicated portfolio for UI/UX design and website development. This project is separate from the Social Media / Video Editing portfolio and does not modify those files or your Desktop project sources.

## Run locally

```bash
cd ~/portfolio
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
